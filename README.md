## មុខងារសំខាន់ៗ (Key Features)

1. **ជ្រើសរើសបន្តតាមប្រភេទ ៣ ជាន់ (3-Level Cascading SPA Selector)** ៖
   - **ជំហានទី ១ — ចំណងជើងជំពូក (`ជំពូកទី១` ដល់ `ជំពូកទី៥` និងទម្រង់គំរូទទេ)**
   - **ជំហានទី ២ — ចំណងជើងមេរៀន (`មេរៀនទី១` ដល់ `មេរៀនទី១៨` បង្ហាញតាមជំពូកដែលបានជ្រើស)**
   - **ជំហានទី ៣ — ចំណងជើងចំណុចរង (`៤៦ ម៉ោងសិក្សា = ៥០ នាទី/ម៉ោង` បង្ហាញតាមមេរៀនដែលបានជ្រើស)**
   - អមដោយប្រអប់ **ស្វែងរករហ័ស (`🔎 ស្វែងរករហ័ស`)** និងប៊ូតុង **មុន / បន្ទាប់**។
2. **ក្រដាស A4 ផ្ដេកបំបែកសន្លឹកដាច់ៗពីគ្នាដូចពេលបោះពុម្ព (1-to-1 Paginated A4 Landscape Sheets)** ៖
   - ទំហំសន្លឹកក្រដាស `297mm × 210mm` ភ្ជាប់ក្បាលតារាងស្វ័យប្រវត្តិគ្រប់ទំព័រ និងលេខទំព័រ `ទំព័រទី ១ / ...` ដោយមិនដាច់បន្ទាត់ជំហាននៅចុងសន្លឹកឡើយ។
3. **រូបមន្តគណិតវិទ្យាស្តង់ដារបោះពុម្ពសៀវភៅពុម្ព LaTeX (KaTeX v0.16.11)** ៖
   - បង្ហាញប្រភាគឈរ `\dfrac{a}{b}`, ស្វ័យគុណ, រ៉ាឌីកាល់, សមីការ, វិសមីការ, ប្រូបាប និងរូបធរណីមាត្រ SVG ស-ខ្មៅច្បាស់ឥតខ្ចោះ។
4. **ទម្រង់រដ្ឋបាលស្តង់ដារ MoEYS ១០០%** ៖
   - ផ្នែកក្បាលរៀបជាជួរឈរតែមួយដោយសញ្ញាត្រេ (`- `) ហើយ **`- សម្ភារៈឧបទ្ទេស ៖` ស្ថិតនៅខាងក្រោម `- វត្ថុបំណង ៖` ជានិច្ច**។
   - តារាង ៣ ជួរឈរ (`២៨% | ៤៤% | ២៨%`) និងបន្ទាត់ចំណងជើង **ជំហានទាំង ៥ ស្ថិតនៅចំកណ្ដាលតារាងជានិច្ច** (`៤ + ៦ + ២៦ + ១០ + ៤ = ៥០ នាទី`)។
5. **បំពេញព័ត៌មានគ្រូ/សាលា កែសម្រួលផ្ទាល់ និងទាញយកជា Word (`.doc`) / PDF** ៖
   - បំពេញឈ្មោះខេត្ត ស្រុក សាលា និងឈ្មោះគ្រូតែម្ដង អនុវត្តគ្រប់មេរៀនទាំង ៤៦ ម៉ោង និងអាចទាញយកជាឯកសារ Microsoft Word (`.doc` ក្រដាសផ្ដេក) ឬបោះពុម្ពជា PDF បានភ្លាមៗលើកុំព្យូទ័រ និងទូរសព្ទដៃ ដោយមិនចាំបាច់ដំឡើងកម្មវិធី Python ឡើយ។
