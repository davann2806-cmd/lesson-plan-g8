## ស្តង់ដារទម្រង់កិច្ចតែងការបង្រៀន (គោរពតាមក្បួនទាំង ៧ នៃ `/lesson-plan`)

1. **ក្បាលរដ្ឋបាល និងចំណងជើងឯកសារស្តង់ដារ** ៖
   - អង្គភាពសាលារៀន ៖ `មន្ទីរអប់រំ យុវជន និងកីឡាខេត្តកំពង់ធំ` / `ការិយាល័យអប់រំ យុវជន និងកីឡាស្រុកកំពង់ស្វាយ` / `អនុវិទ្យាល័យព្រះក្រសាំង`
   - ចំណងជើងធំចំកណ្ដាល ៖ **`កិច្ចតែងការបង្រៀន`** (អក្សរពុម្ព `Khmer OS Muol Light` / `Moul` ដោយគ្មានវង់ក្រចកចំណងជើងរង)។
2. **តារាងព័ត៌មានទំព័រទី១ ចូលបន្ទាត់ក្នុង (`8mm`) និងតម្រឹមសញ្ញា «៖» ត្រង់ជួរឈរតែមួយពីលើដល់ក្រោម** ៖
   - លំដាប់ជួរព័ត៌មានទាំង ៩ ផ្នែក (១៦ ជួរ) ៖ `- មុខវិជ្ជា` (`គណិតវិទ្យា ថ្នាក់ទី៨`), `- ខ្លឹមសារមេរៀន` (`មេរៀនទី... ...`), `- ចំណងជើងរង` (`១.១. ...`, `១.៤. ...`), `- រយៈពេល` (`៥០ នាទី`), `- បង្រៀនដោយ`, `- កាលបរិច្ឆេទ`, `- វត្ថុបំណង` (`+ វិជ្ជាសម្បទា`, `+ បំណិនសម្បទា`, `+ ចរិយាសម្បទា`), `- គោលវិធី និងយុទ្ធវិធីបង្រៀន` (`- គោលវិធី ៖ សិស្សមជ្ឈមណ្ឌល`, `- យុទ្ធវិធីបង្រៀន ៖ តាមបែបរិះរក (5E)`), និង `- សម្ភារៈឧបទ្ទេស` (`+ សម្រាប់គ្រូ`, `+ សម្រាប់សិស្ស`) ហើយបន្ទាត់ចុះជួរទី២ តម្រឹមស្មើក្រោមសញ្ញា `៖` ជានិច្ច។
3. **ក្រដាស A4 ផ្ដេកបំបែកសន្លឹកដាច់ៗពីគ្នាដូចពេលបោះពុម្ព ១០០% (`297mm × 210mm`)** ៖
   - ទំព័រទី ១ រក្សាទុកផ្នែកក្បាល និងតារាងព័ត៌មាន `.meta-table` ពេញលេញ ហើយតារាងមេរៀន `.lesson-table` ចាប់ផ្ដើមស្អាតនៅលើទំព័រទី ២ ជាមួយក្បាលតារាងស្វ័យប្រវត្តិគ្រប់ទំព័រ និងលេខទំព័រ `កិច្ចតែងការបង្រៀន — អនុវិទ្យាល័យព្រះក្រសាំង | ទំព័រទី ១ / ...`។
4. **តារាង ៣ ជួរឈរ (`២៨% | ៤៤% | ២៨%`) និងបន្ទាត់ចំណងជើងជំហានទាំង ៥ ចំកណ្ដាលជានិច្ច** (`៤ + ៦ + ២៦ + ១០ + ៤ = ៥០ នាទី`)។
5. **រូបមន្តគណិតវិទ្យាស្តង់ដារ LaTeX (KaTeX v0.16.11)** ៖ រូបមន្តក្នុងអត្ថបទ `$...$` និងរូបមន្តគោលដាក់ចំកណ្ដាលជួរ `$$...$$` គ្រប់មេរៀនទាំង ៤៦ ម៉ោងសិក្សា ព្រមទាំងអាចទាញយកជាឯកសារ **Microsoft Word (`.doc`)** ឬ **បោះពុម្ព PDF**។
6. **ការជ្រើសរើសបន្តតាមប្រភេទ ៣ ជាន់លើអេក្រង់** ៖ `១. ចំណងជើងជំពូក` › `២. ចំណងជើងមេរៀន` › `៣. ចំណងជើងចំណុចរង`។
